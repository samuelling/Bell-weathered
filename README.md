# Bell Weathered

A browser instrument that plays the weather: a drone and ambient melody machine driven by live conditions, the time of day and the phase of the moon. It is the web sibling of the norns script `bellweather`.

Open `index.html` (or the GitHub Pages site) and press **Begin**.

- 7 drone oscillator models: sine and saw, detuned saws, FM glass, drawbar organ, pulse and width, vowel choir, noise resonator
- 4 melody voices: plucked string (Karplus-Strong), glass bell, kalimba, soft pad
- Live weather from Open-Meteo, or a simulated sky; hold any value by hand
- Sun and moon computed for the chosen place, with a time-lapse control
- A sky that is also the visualiser: the ridge line is the live spectrum, notes ripple the water, the melody grid rains or snows

Single file, no build step, no dependencies. Space starts and pauses, B strikes the bell, M mutes.
